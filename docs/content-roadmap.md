# Content Roadmap — 100 Blog Ideas

Generated as part of the September 2026 SEO/content initiative. This is a
planning document, not published content — no articles have been created
from this list; it exists so future writing work can be prioritised rather
than picked arbitrarily.

**Priority** is a rough estimate based on: existing site content to link
from/to, likely search volume for an Indian audience, and commercial intent
(a booking-adjacent query is worth more than a pure-curiosity one, all else
equal) — not a guarantee, and worth revisiting once real analytics/Search
Console data exists for this site.

**Search intent**: `Informational` (answers a question, no immediate booking
intent), `Commercial` (comparing/planning, close to a booking decision),
`Transactional` (ready to act — visa application, booking a specific thing).

Suggested internal links point to pages that exist today. Update them if
new destination/package/service pages are added later.

## Suggested category architecture, if/when a blog is built

```
/blog
  /blog/destinations/[slug]      (or tag: destinations)
  /blog/visa
  /blog/travel-tips
  /blog/budget-travel
  /blog/luxury-travel
  /blog/honeymoon
  /blog/family-holidays
  /blog/adventure
```

Each post should link back to at least one existing destination, package or
service page (per the "Suggested Internal Links" column above) and forward
to at least one other blog post once enough exist — the goal is a genuine
topic cluster, not 100 isolated pages.

## What this list deliberately does not include

- Any destination this agency doesn't currently sell (no speculative
  "Iceland" or "New Zealand" posts) — adding a blog post about a place with
  no matching destination/package page is an orphan by design.
- Any post requiring a specific price, statistic or visa rule stated as fact
  without a citation — every "Visa" and "Budget" category post above needs
  research against a real, current source at write-time, not generated from
  memory the way this roadmap's titles were.
